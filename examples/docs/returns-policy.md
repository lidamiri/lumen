Returns Policy

Customers may return most products within 30 days of delivery. The item must be unused and in its original packaging.

Refunds are issued to the original payment method within 5 business days after the returned item passes inspection.

Sale items marked final cannot be returned. Gift cards are non-refundable.

Return shipping is free for defective items. For all other returns the customer pays the return shipping cost, which is deducted from the refund.

To start a return, open the order page, select the item and choose Request return. A prepaid label is emailed when the request is approved.
